# Visual correction acceptance

- Preserve workflows, permissions, routes, actions, forms, filters, drawers, canonical statuses and accessibility behavior.
- Home is the minimum visual-quality reference, not a layout template.
- Sparse pages must use the workspace deliberately without fabricating operational data.
- Dense pages must remain efficient and scannable.
- Desktop navigation must not overpower content; mobile must remain fully discoverable without horizontal page overflow.
- Representative screenshots: Requests, Projects, Tasks, Approvals, Review, Shift, Guest Matters and Maintenance, plus mobile states.
- Green CI alone is not visual acceptance; inspect generated screenshots before merge.
- Stop when screenshots meet the target and gates pass; no arbitrary extra styling passes.
